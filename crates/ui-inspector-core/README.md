# tauri-ui-inspector-core

Shared, framework-neutral Rust types and services for [`tauri-plugin-ui-inspector`](https://github.com/mathematic-inc/tauri-plugin-ui-inspector): versioned references, coordinate transforms, image cropping, redaction, persistence, IDs, and the local IPC protocol.

Most applications should depend on `tauri-plugin-ui-inspector` instead. This crate is public for CLI and integration authors.
